# Demonstration

1. Start the backend and load the unpacked extension.
2. Create a profile and add full-body, upper-body and face photos.
3. Open a shopping product or listing page and press **Scan this page**.
4. Select a top and press **Try on**. Explain the `QUEUED` and `PROCESSING` state display.
5. View/download the explicitly labelled mock result.
6. Open a shoes page, add the foot photo once, scan and generate again; this demonstrates profile reuse.
7. Show history and deletion, then demonstrate profile deletion confirmation.
